SQL CRUD — 20 Questions
Setup assumption

Use an employees table with roughly these columns:
employee_id
first_name
last_name
email
department
job_title
salary
city
hire_date
status

You can design the exact schema yourself. That's part of the exercise (Done)

🟢 CREATE / INSERT

1. Create an employees table with appropriate data types and a primary key for employee_id. (Done)

2. Insert one employee into the table with values for all columns. (Done)

3. Insert five employees at once using a single INSERT statement. (Done)

4. Insert a new employee with only the required/basic fields. Let PostgreSQL handle any columns that have defaults. (Done)

🔵 SELECT

5. Retrieve all employees from the table. (Done)

6. Retrieve only the employee's first_name, last_name, department, and salary.  (Done)

7. Retrieve all unique departments from the employees table. (Done)

8. Retrieve the first 5 employees from the table. (Done)

🟡 WHERE / FILTERING

12. Find all employees who live in either Kolkata, Bangalore, or Mumbai (Done)

13. Find all employees whose first name starts with the letter A (Done)

14. Find all employees who are active and belong to the IT department (Done)

🟠 UPDATE
